# 文単位の翻訳

発話の区切り（speech.cpp では無音）ごとに翻訳すると、文の途中で切れた断片がそれぞれ翻訳される。`CaptionPipelineService` で確定した認識結果を `SentenceBuffer` に溜め、文の終わりまでを 1 文ずつ翻訳する。全エンジン共通。文の終わりは `。` `．` `？` `！` `?` `!` と、空白の前か末尾にある `.`（`3.5` は区切らない）。ユーザーの指定は `。` と `.` で、疑問符と感嘆符を加えたのは実装時の判断。断片の連結は、境界の文字がかな・漢字なら空白なし、英字同士なら空白を入れる。未完の文は未翻訳の途中行として表示し、2 秒間新しい認識結果がなければ翻訳する（文の終わりを出さない認識結果で翻訳が止まらないようにするため。2 秒は実装時の判断）。Auto では文ごとに翻訳方向が決まる。

speech.cpp の発話区切りの無音を 0.7 秒から 0.5 秒に短くした。

制約: Qwen3-ASR は途中で切れた発話の末尾にも句点やピリオドを付ける（`Thank you for.`、`今日は会議で。` を確認）。このため Qwen3-ASR を使う `English -> Japanese` と `Auto` では断片がそのまま 1 文として翻訳され、この変更の効果は Haas-ja と Apple Speech に限られる。0.5 秒への短縮で、Qwen3-ASR では断片が増えうる。新しい macOS 権限や OS バージョン要件はない。
