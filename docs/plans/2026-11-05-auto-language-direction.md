# 言語方向の自動切り替え

英語と日本語が交互に出てくる音声のために、言語方向に `Auto (EN <-> JA)` を加える。Apple Speech は 1 ロケール固定で言語を追えないため、Auto では音声認識を speech.cpp に固定し、Qwen3-ASR 0.6B を `--language` なし（自動判定）で起動する。翻訳は英語 → 日本語と日本語 → 英語の 2 セッションを開始時に準備し、発話ごとに認識結果のテキストで振り分ける。かな・漢字を 1 文字でも含めば日本語 → 英語、含まなければ英語 → 日本語とする。worker の応答にある `languages` ではなくテキストで判定するのは、翻訳セッションの入力言語と必ず一致し、1 発話に両言語が混ざった場合や第三言語と誤判定された場合にも同じ規則で決まるため。新しい macOS 権限や OS バージョン要件はない。両方向の翻訳言語がインストールされている必要がある。発話は無音で区切るので、間を置かない言語の切り替えは 1 発話にまとまり、その訳は崩れうる。日本語の認識は Haas-ja ではなく Qwen3-ASR になるため、実際の会議音声での精度評価が必要。
